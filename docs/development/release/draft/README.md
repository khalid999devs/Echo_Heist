## Proposed itch.io page copy

**ECHO HEIST: The Core Rebellion**

Steal an experimental core from a two-floor research facility. Choose a route, use cover, distract security and survive the lockdown on your way out.

**Current development build:** direct-control Human infiltration, patrol and pursuit, timed sprint, crouch/under-desk clearance, Echo, EMP and limited emergency stun. The cinematic opening, mission HUD, pause/settings, result navigation and ending are playable. This is an early functional slice; autonomous Companion/NEXUS, the complete interactive environment, scored reports and persistent Workshop profiles are still in development.

**Planned complete V1:** Human infiltration and autonomous AI-versus-AI infiltration sharing the same world rules; editable four-block Companion policy; readable algorithm diagnostics and comparable mission reports. Advertise these as available only after the connected gates pass.

**Distribution:** free downloadable desktop game. Windows x64 and macOS Apple Silicon are primary targets. Linux is optional after independent desktop QA; browser and Steam are future possibilities. The source repository is [Echo_Heist on GitHub](https://github.com/khalid999devs/Echo_Heist). Confirm public unauthenticated access and archive links at publication time.

Use separate platform downloads with exact version, commit, SHA256 and limitations. Do not post CI runner archives as a fully tested release.
