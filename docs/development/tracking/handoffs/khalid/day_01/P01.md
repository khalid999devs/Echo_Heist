## Map, action and event conventions

- Tile coordinates are `(x, y)`, zero-based, x right/y down; map dimensions are tile counts. StaticMap contains immutable blocked/opaque tile sets, stable map ID, tile pixel size and MapObject tuple. Suhita's P02 loader constructs these values; it does not create a Simulation or change live state.
- MapObject has object_id, kind, tile and tuple of `(name, scalar)` properties. Values are strings/numbers/bools/null, never mutable nested JSON. Static bounds are checked now; unique objective anchors, object-type semantics, five-zone/connectivity/patrol validation belong to P02-S2/P03-S1.
- Instantiate Simulation with unique actor IDs on distinct walkable tiles. `observe(actor_id)` returns its permitted immutable values; `presentation_snapshot()` is separate UI/diagnostic data.
- `step(actions)` advances exactly one tick. Actions must use the current Observation.tick. Multiple intentions for one actor are all rejected; actors resolve in stable ID order. Events use the committed tick and deterministic `tick:sequence` IDs.
- The P01 diagnostic implements cardinal tile MOVE and WAIT only. Unsupported actions/sprint/targets and stale/future intents reject without inventory changes. P02 must replace diagnostic movement with the approved continuous/sprint rules, legal interactions and tools; do not treat one tile per diagnostic tick as final speed.
- P01 exposes no other actors through observations because sensing belongs to P03. Do not replace this with unfiltered world actors when implementing perception. World state/fingerprint remain privileged; MCTS must later use belief state.
- RunResult is the future terminal boundary; no mission outcome or scoring is produced in P01. Approved scoring is unchanged and implemented in P06, not faked in the shell.

## Resources, settings and packaging

Runtime assets/data live in src/echo_heist/resources. The original simple foundation SVG and JSON are bundled in both wheel and native build. Future scene data/assets should use this resource service and meaningful subdirectories with at most six direct files.

Settings schema 1 is flat JSON: schema_version, window_width, window_height, fullscreen, music_volume, sfx_volume, reduced_flashing. Missing fields default; malformed files are backed up (maximum three); newer schemas stay read-only/preserved. Atomic save failure keeps the prior file. Tests inject temporary directories; default runtime data is in the OS application-data location, not the bundle.

```sh
uv run --locked --all-extras python scripts/packaging/build.py
uv run --locked --all-extras python scripts/packaging/smoke.py "dist/Echo Heist.app" --mute
```

On Windows use dist/EchoHeist/EchoHeist.exe as the smoke argument. The spec builds only on the native primary OS/architecture. CI is configured for Windows x64/macOS arm64 builds and Linux checks; hosted runs have NOT_RUN status because there is no remote. CI dummy-video checks are distinct from real display QA.
