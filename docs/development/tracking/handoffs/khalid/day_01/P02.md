## Actual shared API

```python
from echo_heist.core.contracts.results import MissionSpec
from echo_heist.core.simulation.engine import Simulation
from echo_heist.infrastructure.resources import load_game_rules
from echo_heist.ui.input.human import HumanInput, UiCommand
from echo_heist.ui.presenters.objective import build_objective_view, draw_objective

rules = load_game_rules()
# world_map and spawns come from Suhita's validated level/deployment data.
simulation = Simulation(
    world_map,
    spawns,
    rules=rules,
    seed=1042,
    mission=MissionSpec("operative", core_object_id, exit_object_id, mode="HUMAN"),
)
human = HumanInput("operative")
# Feed actual pygame events once per rendered frame; handle returned UI requests.
commands = human.feed(events)
# Exactly once per fixed simulation tick, when unpaused:
result = simulation.step((human.action_for(simulation.observe("operative")),))
snapshot = simulation.presentation_snapshot()  # renderer only, never a controller
view = build_objective_view(
    simulation.observe("operative"), ticks_per_second=simulation.ticks_per_second
)
```

- **Migration:** Simulation now requires explicit `rules`; constructor `ticks_per_second` is replaced by the rules' frequency. The property remains. GameRules is public/immutable at `core/contracts/config/gameplay.py`, so controllers can receive it without importing private Simulation state. The only balance values are in bundled `resources/data/gameplay/phase02.json`, validated by the resource adapter; core does no disk/SDL IO.
- Existing StaticMap/MapObject/ActorSpawn call shapes remain valid. MissionSpec fields are operative_id, core_object_id, exit_object_id, mode (HUMAN or COMPANION). Anchor IDs are selected by the loader, not hard-coded in core; kinds Core/Exit are checked case-insensitively. Omitting mission runs a diagnostic world without extraction/theft.
- Physical positions are integer `(x,y)` values at **30,000 units/tile**, initially at tile centers. OwnStatus.position and EntityView.position are additive optional fields, always populated by this runtime. Tile fields remain integer planning cells. Render with position * tile_pixel_size / 30000. Actor body radius is 0.3 tile; collision uses bounded substeps and wall sliding. Walk/sprint are 2.2/3.6 tiles/s, normalized diagonally; guard speeds are type-specific. There is no stamina.
- Action tick must equal the latest observation tick. One intent per actor; all duplicate intents reject. MOVE uses direction components -1/0/1 and sprint; targets are not movement payloads. Stale/invalid/resource/range failures spend no stock. Processing is stable by actor ID. Melee/interaction reach is checked again after all movement.
- Only the configured operative can take/extract the Core. INTERACT (optional target_id) is a continuous 24-tick valid hold, reset by release, movement or invalid input. Theft atomically sets inventory/owner, LOCKDOWN, CORE_TAKEN and LOCKDOWN_STARTED, once. The carrier crossing the configured original Exit tile wins; another actor crossing it does not. Terminal states freeze future steps and emit no duplicate events.
- StepResult gains **mission_end: MissionEnd | None**; PresentationSnapshot carries it too. MissionEnd has outcome, elapsed_ticks, operative_id, capture_by. **Use this unscored outcome in P02 result views.** Existing StepResult.terminal remains None until P06 implements approved scoring; no fake score/rank was introduced. `simulation.step(abort=True)` records voluntary ABORTED through the mutation boundary after the scene's confirmation flow.
- Adjacent physical contact with line of reach starts capture. It is not LOS/identification AI. Escape cancels; EMP/melee resolve before completion; completed capture beats extraction on the same tick. Mission endings clear active grab telegraphs. Discovery/noise/lockdown/empty stock never cause defeat themselves.
- Initial real tools: three nonregenerating Echo charges, 75-tick reverse path decoys; one nonregenerating EMP, 2.5-tile radius/90-tick disable; one reachable melee target, 45-tick stun plus 60-tick recovery immunity. Immune repeated melee still makes noise. EMP follows radial range; melee/capture require clear reach. Decoys are separate EchoView values, not actors with inventories/actions. Guard perception of Echo belongs to P03; environment/effect completion belongs to P05.
- **Event units:** ACTOR_MOVED x/y are fixed-point positions; NOISE_CREATED x/y are tile coordinates and radius_tiles is in tiles. Guard timer events include until_tick; capture includes target_id/completes_at_tick. Events are committed tick:sequence IDs. Do not feed the global event stream or other actors' observations to controllers.
- OwnStatus adds interaction_progress_ticks and capture_ticks_remaining; Observation adds immutable interactions (InteractionHint). P02 remains own-only except legitimate contact feedback; full sensing/reports are P03. PresentationSnapshot adds echoes, captures, core_owner and actor disabled/stunned flags. These privileged rendering values are never controller input.
- `HumanInput.feed(events)` returns PAUSE, FOCUS_LOST, OBJECTIVE, LAB or QUIT scene requests. PAUSE toggles; FOCUS_LOST sets pause explicitly. Clear input on pause/restart/scene switch, run zero steps while paused and discard accumulated catch-up time. Tools trigger once per press, queues are bounded, and one cached action is produced per observation tick. KeyBindings supports explicit remapping without a settings UI implementation.
- `build_objective_view` reads only an Observation. It returns objective/interaction/inventory/elapsed/warning text. `draw_objective(surface, view, font, ...)` is optional; Suhita may render the same immutable values in her own layout. Gameplay legality/progress comes from Simulation, never widgets.
