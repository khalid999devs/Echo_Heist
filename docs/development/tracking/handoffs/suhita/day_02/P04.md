## Implemented behavior

**SR1 Companion** (`ai/companion/`, `ai/planning/mcts.py`, `ai/navigation/routes.py`)
- Mission FSM INFILTRATE -> REACH_CORE -> TAKE_CORE -> EXTRACT (-> WIN / CAPTURED) over the same Simulation, actions, speeds, tools and stock as the Human.
- Knowledge: public briefing (map, zones/chokepoints, under-desk cover, Core/Exit, guard roster with type and home sector) plus its own Observation. Sightings decay into hypotheses; unseen guards are sampled from the briefed home-sector prior. No hidden positions, no radio, no recording.
- Utility overrides every tick: grabbed -> EMP / melee / pull away per the Emergency block; adjacent watched guard -> melee/EMP/escape; in a cone -> break line of sight (flee forward, or back along remembered tiles when the watcher is close ahead; Echo first for CONSIDER_ECHO). Melee respects post-stun immunity; EMP and Echo are reserved for real threats.
- Strategic MCTS (64 iterations, depth 4, UCT c=0.25, seeded) at deployment, new sightings, junctions, objective changes, stalls/being stuck and finished holds. Open-loop determinization: each iteration samples guard sectors from beliefs; selection, one-action expansion, ADVANCE-biased seeded playout and backpropagation of the normalized blueprint reward (+100 extraction, +30 per objective step, -capture, -detection, -5 per gadget, -time; policy-scaled). Legal set: ADVANCE, ALTERNATE (only on observed danger), WAIT, HIDE (cover reachable, unwatched, recent sighting), RETREAT, ECHO (a guard in view), EMP/MELEE (observed range). A stale/illegal choice falls back to WAIT and re-plans. No progress for 20 s excludes holds at the root.
- Observed-risk A*: existing admissible stair-aware A*, plus nonnegative penalties for observed cones (decaying 3 s), visible bodies and locally jammed one-tile corridors. Side-steps bodies in two-lane corridors.

**SR2 defenders** (`ai/guards/interceptor.py`, `ai/planning/minimax.py`, `ai/director/nexus.py`, `core/simulation/systems/security.py`)
- Interceptor (registry role `INTERCEPTOR`, label `ALPHA-BETA`, Core guard identity unchanged): on a new radio sighting, a NEXUS INTERCEPT order (Core alarm) or its own lost sighting, it enumerates up to three plausible zone routes from that evidence tile/original tick to the current goal, searches depth-3 MIN post / MAX branch / MIN redeploy over its own home gates, and walks there with A*. Holds during lockdown; returns otherwise after its evidence ages. Alpha-beta equals minimax on the same tree (shared order and strict tie rule).
- NEXUS each tick (before guards decide): view = guard-heard cues, guard-seen motion, radio sightings, public phase/alarm and its own robots. Tasks: PROTECT_EXIT 100, INTERCEPT 90, SUPPORT_PURSUIT 80, strong noise 45; stable order, per-task caps, at least one routine patrol kept, support radius 18 walking tiles. Orders are addressed `DISPATCH` reports with the original evidence tick; Sentinel/Tracker follow them only when not already chasing/searching. One lockdown announcement. Counts witnessed Echo decoys, contacts per sector (once per pursuit) and grouped bypasses.

**SR3 protocols/deployment** (`ai/director/protocols.py`, `infrastructure/persistence/protocols.py`, `autonomy/`)
- `NexusGateway` implements Khalid's `AutonomyGateway`; advertises HUMAN and COMPANION with protocols. Human actions are forwarded unchanged (identical events/fingerprint to a direct Simulation); Companion mode ignores input and asks the controller. Telemetry is cached after each step.
- `nexus-memory.json` (schema 1) beside settings: missing -> baseline, corrupt -> quarantined `nexus-memory.corrupt-<ns>.json`, future schema -> protocols unavailable and file untouched. Evidence is recorded once per finished attempt; at most one protocol (threshold 2) is selected for the next attempt, shown before deployment, announced at tick 0 and fixed for the attempt: VERIFY_ECHO (motion only investigated within 4 tiles), REINFORCE_ROUTE (Interceptor holds the home gate into the reinforced sector), SPREAD_FORMATION (no pursuit support, wider routine coverage). Reset clears every input and reproduces the baseline fingerprint.
- Startup hook: `run_desktop` -> `open_game(data_dir=...)` -> `StartupLoader` builds the gateway on the worker and injects `GameFlow(..., autonomy_gateway=gateway)`. No render/camera/layout/art/map edits.

## Known limitations (nonblocking for this slice, recorded honestly)

- Win rates are modest and preset-dependent (Balanced 11/24, Rush 8/24, Ghost 2/24 over seeds 0-23). The default Balanced preset loses on seed 1042. Policy tuning/seed selection is P06/P07 work.
- In calm states MCTS values are often close; visits then spread across alternatives. Decisions remain real and deterministic.
- Two guards can still body-block each other in a one-tile corridor (pre-existing P03 steering behavior that NEXUS dispatch makes more likely). Not fixed in this slice.
- Protocol memory has no settings toggle yet (P06); memory is enabled by default.
