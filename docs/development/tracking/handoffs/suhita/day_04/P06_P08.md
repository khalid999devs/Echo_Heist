## What now works

- **Scoring (P06-SR1):** every finished run gets the approved score from the Simulation: completion 50, stealth 40 − 12 per team detection encounter, pace up to 10; S/A/B/C on a win, 0/F otherwise; Ghost/AI Master/Speedrunner labels. Encounters are tracked by Simulation exactly as SCORING.md defines.
- **Reports, history, profiles, preferences (P06-SR2/SR3):** the real `ExperienceGateway` is installed at startup. Results show the authoritative report; history persists (100); named Workshop profiles save/overwrite/load/delete (32); controls/captions/contrast persist. Damaged files are kept aside once, newer files are never overwritten. Backend presets are shared with the Workshop. `NexusGateway.set_protocols_enabled` persists a NEXUS memory on/off switch (UI toggle not built).
- **Harness and fixes (P07-SR1/SR2):** 24-scenario registry, Companion harness with full metadata and separate timing, comparison runner, and a fix for guards deadlocking each other in narrow corridors. The algorithm guide text matches the running algorithms.
- **Comparison (P08-SR2):** 96 runs executed and analyzed; identical on Suhita's computer.

## Known limitations

- Win rates are modest (Ghost 3/24, Balanced 8/24, Rush 13/24, Custom 11/24) and no run reached S or Ghost; balance tuning is outside the functional phases.
- The pace reference stays at the draft 27,000 ticks, so every win gets 10 pace points; it should be calibrated from real Human playtest times plus the measured Balanced wins (report section "Pace calibration input"). The Speedrunner threshold is also a draft.
- Report labels use the profile name only after the profile list has been loaded in that session.
- If a history write fails, that run's score is still shown but the run is missing from saved history.
