## Known limitations

- Win rates are modest (Ghost 3/24, Balanced 8/24, Rush 13/24, Custom 11/24) and no run reached S or Ghost; balance tuning is outside the functional phases.
- The pace reference stays at the draft 27,000 ticks, so every win gets 10 pace points; it should be calibrated from real Human playtest times plus the measured Balanced wins (report section "Pace calibration input"). The Speedrunner threshold is also a draft.
- Report labels use the profile name only after the profile list has been loaded in that session.
- If a history write fails, that run's score is still shown but the run is missing from saved history.
